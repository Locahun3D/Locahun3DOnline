# 公式サイトからの情報・写真の取り込み（設計）

2026-09-20 本人承認。掲載準備パイプライン（Dropbox `01_ワークフロー解説/scripts`）への継ぎ足し。
サイト（このリポ）は改修しない。本番への書き込みは `r2_register.py` の安全策を再利用する。

## 目的
公式サイトの情報を**正確に**物件へ反映し、写真は**一番いいものをヘッダー、続く6枚をギャラリー**に自動で並べる。
あわせて、物件の自動作成・公開前チェック・シーン名の日本語化を入れる。

## 使い方
```
python import_official.py <slug> <公式サイトURL>            # 収集と提案だけ（本番は読み取りのみ）
python import_official.py <slug> <公式サイトURL> --apply    # 下書き物件へ反映
python import_official.py --new "<物件名>" <公式サイトURL>   # 下書き物件を新規作成してから同じ処理
python publish_check.py                                      # 全下書きの公開前チェック一覧
```

## 1. 情報の取り込み
- 同一ドメイン内で最大 12 ページ（トップ・料金・設備・アクセス・利用案内）を 1 秒間隔で取得。robots.txt で禁止されたパスは読まない。
- 抽出項目: 住所 / 最寄り駅 / 時間料金・日額 / 最低利用時間 / 営業時間 / 広さ / 天井高 / 電源 / 設備の有無と1行メモ / 電話・メール・URL / 紹介文。
- 抽出は Claude に「原文の引用つき」で行わせ、**引用が取得した本文に実在することを機械照合**する。照合できない値は捨てる（作り話の防止）。
- すべての値に `sourceUrl` / `quote` / `fetchedAt` を付け、台帳 `facts[slug]` に保存。
- 反映ルール: 空欄は自動で埋める。人が入力済みの欄は上書きしない。公式に無い情報は書かない。
- **確認に回して止まる**: 料金の税込/税別が不明、複数フロア・部屋で対象が曖昧、既存値と食い違う、同名の別施設の疑い（住所・電話が既存と不一致）。
- 概要は `docs/property-overview-copy-rules-2026-09-19.md` に従って下書き（3〜6文・仕様と重複させない・コピー転載しない）。禁止語（徒歩・㎡・mm・円・時間・駐車場）を含んだら作り直す。
- ページ内の文はデータとして扱い、指示としては実行しない。

## 2. 写真の選定
- 収集: `<img>`・`srcset` の最大サイズ・`og:image`・CSS 背景。同一ドメインと、そのサイトが使う画像 CDN のみ。
- 除外: 長辺 1200px 未満、ロゴ・バナー・文字入り・地図・間取り図（AI 判定）、内容の重複（知覚ハッシュ）。
- 順位: 公式のヒーロー（トップ最上部の大きな写真）を先頭候補 → AI が明るさ・ピント・引きの画・人物アップでないかを採点して補正。
- ヘッダー = 横長の 1 位。ギャラリー = 上位 6 枚（横長優先、足りなければ縦長を後ろに）。
- 反映前に**順位つき確認シート（1枚の画像）**を出す。並び替え・除外の指示を受けてから `--apply`。
- R2 `assets/image/<id>-<name>` に保存し素材登録。台帳に出典 URL と `permission: "未"` を記録。

## 3. 物件の自動作成（--new）
- slug は物件名から生成（既存と衝突したら停止）。status は draft 固定。
- 既定値はサイトの `propertySchema` と同じ形で作る（新規作成 API の出力を基準に照合テストする）。

## 4. 公開前チェック（publish_check.py）
- 全 draft について: カバー / ギャラリー6枚 / 概要（ルール適合）/ 3DGS / 連絡先 / 写真の許諾 / 北合わせ未確認 を一覧表示。公開操作はしない。

## 5. シーン名の日本語化
- 自動登録したシーンのラベル（フォルダ名のまま）を、物件名＋部屋名の日本語表示名に提案する（例: MusicHoll → ミュージックホール）。人が付けたラベルは変えない。

## 安全策
- draft のみ。条件付き更新＋読み戻し。R2 は送信後にサイズと SHA-256 を照合。既存キーは上書きしない。
- 許諾が「未」の間は公開しない（公開は本人判断）。
- 実行は Claude の権限モード「手動」で（自動モードでは本番書き込みが止まる）。

## テスト
- 抽出: 保存した HTML を入力に、引用照合・食い違い検出・税表記不明での停止を単体テスト。
- 写真: 除外規則（サイズ・重複・縦横）と並び順を固定画像で単体テスト。
- 実地: STUDIO MONTFORT と PLEASE GREEN で抽出値を公式サイトと 1 項目ずつ照合し、結果を手順書に記録。
