# 英語版（/en/*）翻訳監査 — 2026-09-20

本人指示「今のページも翻訳できていない箇所多いのですべてのページをスクショなどで調査」への回答。

## やり方

- `node scripts/i18n-audit.mjs [--base http://localhost:3007] [--out artifacts/i18n-audit] [--no-shots] [--props N]`
  - 実 Chrome（Playwright `channel: "chrome"`）で公開ルート 24 本 × 1440 / 390 幅を開き、`<details>` を全部開いてから、
    日本語（かな・カナ・漢字・全角の句読点／括弧／波ダッシュ）を含む**可視テキスト**と
    `placeholder` / `title` / `aria-label` / `alt` / `<option>` / `document.title` / meta description を収集。
  - `data/properties.json` の値と一致するものは「UIではなくデータ」に分ける。Clerk ウィジェット内部（`.cl-*`）は対象外。
  - 意図して日本語のまま出す箇所は `data-i18n-audit-ignore` を付ける（今回は規約内のハッシュタグ `#ロケハン3D` だけ）。
  - 全ページのフルページスクショを `<out>/<page>-<幅>.png` に保存（`artifacts/` は git 管理外）。UI の漏れが1件でもあれば終了コード 1。
- 対象: `/en` `/en/properties` `/en/properties/<id>` `/en/pricing` `/en/about` `/en/contact` `/en/contact/{scan,request,listing,license}`
  `/en/cart` `/en/privacy` `/en/terms` `/en/terms/{data-download,listing-revenue-share,service,submission,tokushoho}`
  `/en/sign-in` `/en/sign-up` `/en/submit-scan` `/en/unsubscribe` `/en/share/x`（404） `/en/this-page-does-not-exist`（404）
- 手元の物件データは `wh-002` 1件だけで項目が少なく、物件ページの多くの欄（料金プラン・割増・規約・設備メモ・アクセス等）が描画されない。
  そこで**一時的に全項目を ASCII 値で埋めた物件**でもう一度スキャンした（スキャン後に `git checkout data/properties.json` で復元。コミットしていない）。
  値が ASCII なので、この時に出る日本語はすべて UI 由来。
- 画面に出てこない状態（送信エラー・購入エラー・サインアウト中継・共有プレビュー帯）は、公開側コンポーネントの静的スキャン
  （`en ?` で守られていない日本語リテラルの洗い出し）で補った。
