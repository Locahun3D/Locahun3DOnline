# ヘッダー設計ルール（両サイト共通・2026-07-28 制定）

ヘッダーは10回以上修正して「1端末を直すと別端末が崩れる」を繰り返した。
原因は個々の実装ミスではなく**構造そのもの**だったので、ここにルールを固定する。
ヘッダーを触る前に必ず読むこと。

対象: `locahun3d_online/src/components/site-header.tsx` と
`digiroke3d_Web/assets/site-header.css`（この2つが唯一のソース）。

## 何が起きていたか（2026-07-28 実測）

| 幅 | 構造 | トグル | ヘッダー高(online/scan) |
|---|---|---|---|
| <720px | **2段**・ナビそのまま | 8px / 2px 4px | 54 / 74 |
| 720–1023px | ハンバーガー | 9px / 3px 6px | 52 / 56 |
| ≥1024px | 1行フルナビ | 9px→11px(≥1200) | 52 / 56 |

iPhone 15 は縦390 / 横844。**回転すると720pxを跨ぎ、構造も寸法も別物になる。**
iPhone SE は横でも667pxなので**SEだけ横向きでも2段**。
端末ごとに落ちる帯が違うため、1帯を直すと別帯が壊れる。

## ルール

### R1. 構造は2つだけ。2段ヘッダーは作らない
- `<1024px` … ハンバーガー ＋ 中央ブランド
- `≥1024px` … 1行フルナビ ＋ 中央ブランド

2段構成は「同じサイトなのに構造が3種類ある」状態を生み、回転で別物になる元凶だった。

### R2. ブランド・トグル・EN の寸法は全幅で固定（最重要）
幅で文字サイズや余白を変えるかぎり、**回転で必ず見た目が変わる**。
縦と横で幅が違う以上、境界をどこに置いても必ず跨ぐ端末が出るため、
「跨がない境界を探す」は原理的に不可能。**寸法を変えないことが唯一の解。**

> 回転で「要素が増減する」ことは避けられない（幅が違う以上、入る数は変わる）。
> 避けられるのは「**同じ要素の見た目が変わること**」。後者を絶対に許さない。

### R3. 入り切らないときは「縮める」のではなく「ドロワーへ移す」
R2 の帰結。狭い画面では EN・カート・認証などをドロワー（ハンバーガーの中）へ退避させる。
**バーに残す要素は ☰ / ブランド / トグル の3つを最優先**とする。

### R4. 中央の定義は全幅共通＝「ブランド単体の水平中心 = 50vw」
- グループ（ブランド＋トグル）中央寄せは禁止。トグル幅の半分ずれ、両サイトで揃わない
- 基準は `100vw` の50%。`inset-x-0` だけだとスクロールバー予約分（15px）で両サイトが7.5pxずれる
  → `translateX(calc((100vw - 100%) / 2))` で戻す（online は zoom があるので `100vw/var(--z)`）
- ⚠ 中央グリッドは `absolute` なので **z-index を明示**する。右側グループが `flex-1` で
  行の中央から右端まで箱を広げており、`relative z-[1]` を持つため、
  z 指定を忘れるとブランドとトグルがクリックできなくなる（実測済み）

### R5. 外周の padding だけは幅で変えてよい
要素そのものの見た目が変わらないため。狭い画面で横幅を稼ぐ手段はこれを最初に使う。

### R6. 同じ要素は両サイトで同一値。切替点も同一
数値を変えるときは**必ず両サイト同時**に。`header-parity.mjs` が機械照合する。

### R7. 触ったら本番でハーネス4本
```bash
node scripts/header-live.mjs         # 本番・ブランド中心/重なり/はみ出し
node scripts/header-parity.mjs       # 両サイトの共有要素の computed style
node scripts/header-consistency.mjs  # スキャン19ページ×23幅が1pxも違わない
node scripts/ui-audit.mjs            # 26ページ×9幅の重なり・はみ出し
```

## 過去の失敗（同じ轍を踏まないために）

- **帯ごとに「中央の作り方」を変えた** → 1199→1200 の1px境界でブランドが84px飛び、
  PC帯では両サイトが26.8pxずれた（2026-07-28 修正）
- **上限を付けた中央機構**（`max-[1024px]` → `max-[1200px]`）→ 同じ失敗を2回。
  中央機構に**幅の上限を付けない**
- **切替点を下げたら、その帯だけに出ていた要素が消えた**（トグルが768–1279pxで消失）
  → 切替点を動かしたら、その帯域を必ずスクショで目視する
- **CSSを各HTMLへコピペ** → 3系統にdriftし「ページによって文字サイズが変わる」
  → `assets/site-header.css` 1本＋`sync_header.py` で同期
