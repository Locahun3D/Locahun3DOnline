# 物件ページ「概要」の制作ルール（2026-09-19 本人指示）

> 指示: 「概要はフレーバーテキストを公式サイトから持ってくる方針で。他で書いてある情報がダブって意味がないことが多い」
> 「文節ごとの改行などのデザインが終わっている。デザインをしっかり調べて制作時のルールにしてくれ」

## 1. 内容のルール（何を書くか）

**概要＝フレーバーテキスト。** その場所の空気感・見どころ・撮れる画を伝える文章。
根拠は公式サイトの紹介文（コンセプト文・キャッチコピー・空間の説明）。

| 書く | 書かない（→ 仕様欄・アクセス欄に出る） |
|---|---|
| 空間の印象（光・素材・色・広がり） | 駅からの分数・路線名 |
| 何が撮れるか（向いている画・シーン） | 広さ ㎡／坪・天井高 mm |
| 他にない特徴（建具・眺望・造作・時間帯の表情） | 営業時間・最低利用時間・延長単位 |
| 使われ方の実績（MV・スチール・展示など、公式が書いていれば） | 料金・割増 |
| | 駐車場の有無・エレベーターの有無・搬入経路 |
| | 設備の一覧（アイコン欄にある） |

- **3〜6文。1文は 40 字前後まで。** 長い1文は分ける（表示は1文1行なので、長いと3行にまたがる）。
- 公式サイトの文をそのまま貼らず、**事実を保ったまま言い換える**（コピー転載を避ける）。数値・固有名詞は変えない。
- 公式に無い情報を足さない。「不明」は書かない、空欄でよい。
- 注意事項（土足不可・火気・近隣配慮）は概要ではなく `notes` / 利用条件へ。
- `【見出し】` 行は複数フロアなど区切りが要る時だけ。

### 書き換え例（STUDIO MONTFORT）

現状（仕様の繰り返し）:
> 副都心線「雑司ヶ谷駅」1番出口より徒歩5分、池袋からも徒歩圏の自然光レンタル撮影スタジオです。広さ約80㎡（約24坪）、天井高は一番高いところで3,300mm。白を基調とした…利用可能時間は7:00〜20:00、最低利用は2時間からです。エレベーターはなく…専用駐車場はございません。

書き換え案（フレーバー）:
> 白を基調にした明るい部屋に、フレンチアンティークの建具とレンガ柄タイルが静かに馴染むスタジオです。
> 大きな窓から入る自然光が、磁器質タイル・木・石の床にそれぞれ違う表情を落とします。
> アーチ窓のある一角は、ポートレートや小物のスチールで背景として映えます。
> 家具を寄せれば約80㎡がひとつながりになり、動きのあるムービーにも向きます。

（駅・天井高・時間・駐車場・階段は仕様欄に任せる）

## 2. 表示のルール（実装済み）

日本語ウェブ本文の基本（サイト共通ルール `CLAUDE.md` と同じ）:

- **1文＝1行。** 句点「。」の後で改行する（`renderOverview` → `sentenceLines` が自動で `<br />`。編集画面で改行を入れる必要はない）。閉じ括弧「」）の直前では切らない。
- **1行に収まらない文は文節で折り返す。** `body` の `word-break: auto-phrase`（Chrome/Edge は BudouX 内蔵）で「徒歩圏の｜自然光」のような文節境界のみで折れる。禁則は `line-break: strict`。
- **行間 1.95・字間 0.04em・文字色は ink/85。** 段落幅は `max-w-[36em]`（1行 30〜36 字＝日本語で読みやすい上限）。
- **1文が3行以上になったら内容側で分ける。** 表示側で詰めない。
- 数値と単位（3.3 m など）は分離しない（メトリクス枠で表示）。
- 英語（EN 版）は自然折り返しのまま（句点改行はしない）。

参考にした慣行: 日本語組版処理の要件（JIS X 4051 の禁則）、文節分かち書き（BudouX）、Web 本文は 1 行 35 字前後・行間 1.7〜2.0 が可読性の目安。

## 3. 概要カードの構成（2026-09-19 変更）

```
概要
  本文（1文1行）
  平面図（画像はその場で表示・クリックで原寸。PDF はダウンロード札）
  天井高 / 面積 のメトリクス
```

平面図は仕様カード末尾の「ダウンロード」札から、概要カードの空きスペースへ移動（本人指示「視覚的にわかりやすいように」）。

## 4. 制作時のチェック

- [ ] 3〜6文、各文 40 字前後
- [ ] 公式サイトに無い事実を足していない
- [ ] 1440 / 820 / 390 で1文が3行にまたがっていない
